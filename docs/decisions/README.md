# Decisiones arquitectónicas

Los ADR documentan decisiones que deben mantenerse visibles entre sesiones y equipos.

## ADR existentes

Todavía no hay ADR individuales formalizados. La arquitectura actual está descrita inicialmente en [architecture.md](../architecture.md) y las decisiones del refactor se convertirán en ADR antes de modificar límites estructurales.

## Cuándo crear un ADR

- Cambia un límite entre Site, Web, API o contratos.
- Se introduce o elimina una dependencia importante.
- Se cambia el modelo de autorización o tenant.
- Se cambia una máquina de estados.
- Se decide mantener o abandonar una alternativa arquitectónica.

Usar la plantilla [ADR](../templates/adr.md).
